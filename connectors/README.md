# راهبرد اتصال منابع
هیچ اتصال زنده‌ای به‌صورت پیش‌فرض فعال نیست. منابع فقط از طریق API مستند، فید محصول، همکاری تجاری یا روش مجاز متصل می‌شوند.
برای هر اتصال، شرایط استفاده، robots policy و محدودیت درخواست‌ها بررسی شود؛ منبع، شناسه کالا، فروشنده، لینک، قیمت، ارز، وضعیت موجودی، امتیاز (فقط در صورت ارائه منبع) و زمان آخرین بررسی ثبت شود.
مدل‌ها، ظرفیت‌ها، رنگ‌ها، وضعیت نو/دست‌دوم و بسته‌ها با هم یکی نشوند. داده قدیمی مشخص شود. CAPTCHA، ورود، paywall یا کنترل فنی دور زده نشود. اگر API یا فید مجاز وجود ندارد، لینک منبع نمایش داده شود یا درخواست همکاری شود.
استخدام، ملک و خدمات باید موتور جست‌وجو و ساختار داده جداگانه داشته باشند.
