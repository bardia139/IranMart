# راهبرد اتصال منابع

## زیرساخت اجراشده
- API مستقل جست‌وجو روی Cloudflare Workers: `https://iranmart-catalog-api.v80bk-85ck7f37a0-gpsy06m8h.workers.dev`
- پایگاه داده Cloudflare D1: `iranmart-catalog`
- همه ۴۰ منبع در جدول `sources` ثبت شده‌اند.
- مسیرهای API: `GET /health`، `GET /sources`، `GET /search?q=...` و ورود امن داده از `POST /admin/import`.
- ورود داده فقط با توکن مدیریتی سمت سرور مجاز است؛ توکن در کد فرانت‌اند یا مخزن قرار نمی‌گیرد.

## وضعیت واقعی
زیرساخت آماده است، اما هیچ منبع فروشگاهی/آگهی هنوز داده زنده وارد نکرده است. هر منبع فقط با API رسمی، فید محصولی که مالک آن اجازه داده، قرارداد همکاری یا داده‌ای که صریحاً مجوز بازنشر دارد فعال می‌شود. نام منبع در فهرست به معنی اتصال زنده نیست.

## قرارداد داده
هر پیشنهاد باید شناسه خارجی پایدار، عنوان، لینک HTTPS صفحه اصلی، نام فروشنده در صورت ارائه منبع، قیمت و واحد پول، موجودی/وضعیت در صورت ارائه منبع، وضعیت نو/دست‌دوم و زمان مشاهده داشته باشد. قیمت، امتیاز، نظر و موجودی حدس زده نمی‌شود. مدل، ظرفیت، رنگ، سایز، بسته و وضعیت نو/دست‌دوم با هم ادغام نمی‌شوند.

## دسته‌های جدا
کالاهای فروشگاهی، آگهی‌های عمومی، خودرو، ملک، استخدام و خدمات در فیلد گروه مستقل می‌مانند و نباید در یک نتایج کالایی ادغام شوند.

## محدودیت‌های دسترسی
CAPTCHA، ورود، paywall، محدودیت نرخ یا کنترل فنی دور زده نمی‌شود. اگر API یا فید مجاز در دسترس نباشد، منبع با وضعیت «نیازمند API، فید یا مجوز همکاری» باقی می‌ماند و فقط لینک منبع نمایش داده می‌شود.

برای جزئیات وضعیت دسترسی هر منبع، `connectors/access-matrix.md` را ببینید.
