# وضعیت دسترسی منابع ایران‌مارت

این سند وضعیت اتصال را از «ثبت نام منبع» جدا می‌کند. وجود نام یک سرویس در فهرست، به معنی دسترسی به داده‌های آن نیست.

## بررسی اولیه مسیرهای دسترسی

| منبع | مسیر بررسی‌شده | نتیجه فعلی |
|---|---|---|
| دیجی‌کالا | API فروشندگان | API فروشندگی با ثبت کلاینت و توکن دسترسی برای عملیات فروشنده مستند شده؛ دسترسی عمومی به کاتالوگ/قیمت همه فروشندگان از آن نتیجه نمی‌شود. برای چنین استفاده‌ای مجوز جداگانه لازم است. |
| ترب | فید فروشگاه | راهنماهای فنی در دسترس درباره فید محصول فروشگاه برای ثبت کاتالوگ خود فروشنده‌اند؛ این را API عمومی جست‌وجوی تمام فروشندگان تلقی نمی‌کنیم. |
| باسلام | API/SDK فروشندگی | SDK جامعه‌محور عملیات فروشنده را پوشش می‌دهد؛ تا زمان تأیید رسمی باسلام، منبع مجاز عمومی برای جست‌وجوی همه غرفه‌ها محسوب نمی‌شود. |
| ایمالز | همکاری/فید | API عمومی مستند و مجاز برای این کاربرد در بررسی اولیه تأیید نشد؛ درخواست همکاری لازم است. |
| دیوار و شیپور | API/همکاری | API عمومی مستند و مجاز برای تجمیع آگهی در بررسی اولیه تأیید نشد؛ درخواست دسترسی/همکاری لازم است. |

## وضعیت سایر منابع

برای تکنولایف، بانی‌مد، مدیسه، ایسام، ایستگاه، ایران تجارت، ویوا استریت، اکالا، اسنپ‌مارکت، روبینو، موبایل۱۴۰، خانومی، دیجی‌استایل، باما، همراه مکانیک، خودرو۴۵، کارموند، کیلید، آی‌هوم، ملک۱۱۸، علی‌بابا، B2B ایران، بانی پخش، گیسوم، ایران‌کتاب، ۳۰بوک، طاقچه، فیدیبو، زومیت، جابینجا، ایران‌تلنت، جاب‌ویژن، پونیشا و کارلنسر هنوز دسترسی رسمی/فید متناسب با نوع داده در این پروژه تأیید نشده است. برای هرکدام باید مستندات رسمی، شرایط استفاده و مجوز داده بررسی شود.

## قواعد پذیرش اتصال

1. فقط API رسمی، فیدی که مالک/فروشنده اجازه داده، قرارداد همکاری یا داده‌ای که صریحاً مجوز بازنشر دارد.
2. API فروشندگی فقط برای داده‌های همان حساب فروشنده استفاده می‌شود؛ به عنوان مجوز برداشت کاتالوگ سایر فروشندگان تلقی نمی‌شود.
3. داده‌های آگهی، خودرو، ملک، استخدام و خدمات در جداول/جست‌وجوهای مجزا نگهداری می‌شوند.
4. قیمت باید همراه واحد پول و زمان مشاهده ذخیره شود؛ داده بدون قیمت در مقایسه قیمت وارد نمی‌شود.
5. اگر مجوز یا API وجود نداشته باشد، فقط لینک صفحه اصلی منبع و وضعیت «در انتظار دسترسی» نشان داده می‌شود.
6. هیچ CAPTCHA، ورود، paywall یا محدودیت فنی دور زده نمی‌شود.
