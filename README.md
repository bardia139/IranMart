# ایران‌مارت

موتور جست‌وجو و مقایسه منابع ایرانی؛ نسخه اولیه رابط کاربری.

## اجرا
نیازمند Node.js 20 یا بالاتر:
```bash
npm install
npm run dev
```
سپس http://localhost:3000 را باز کنید.

## وضعیت فعلی
- رابط فارسی و راست‌چین
- دسته‌بندی اولیه و جست‌وجوی محلی
- فهرست منابع پیشنهادی
- داده‌های نمایشی و غیرواقعی

**هیچ فروشگاه یا منبع آگهی هنوز متصل نیست.** اتصال هر منبع نیازمند API، فید رسمی، همکاری یا روش دسترسی مجاز است. اطلاعات قیمت، موجودی، امتیاز و نظر تا زمان دریافت داده معتبر نمایش داده نمی‌شوند.

## تنظیمات محیطی
در صورت راه‌اندازی Supabase، مقادیر فایل `.env.example` را در محیط استقرار تنظیم کنید. اتصال دیتابیس در این نسخه فعال نشده است.

## استقرار
این پروژه فعلاً یک برنامه Next.js استاندارد است. برای انتشار روی Cloudflare باید adapter سازگار Next.js (مانند OpenNext برای Cloudflare Workers) و تنظیمات build/deploy اضافه شود.
