# ایران‌مارت — نسخه آغازین

موتور جست‌وجو و مقایسه پیشنهادهای خرید از منابع ایرانی، با رابط فارسی و راست‌چین.

## وضعیت فعلی
- رابط اولیه جست‌وجو، دسته‌بندی و نمایش نتایج آزمایشی آماده است.
- فهرست منابع برنامه‌ریزی‌شده در `src/lib/sources.ts` نگهداری می‌شود.
- **هیچ فروشگاه یا منبع آگهی هنوز به داده زنده متصل نیست.**
- نتایج نمونه، قیمت و فروشندگان ساختگی‌اند و برای آزمایش رابط هستند؛ نباید مبنای خرید قرار بگیرند.
- اتصال ورود پیامکی، کاربران و دیتابیس هنوز فعال نشده است.

## اجرای محلی
نیازمند Node.js 20 یا بالاتر:
```bash
npm install
npm run dev
```
سپس `http://localhost:3000` را باز کنید.

## استقرار روی Cloudflare Workers
این پروژه Next.js 15 است و پیکربندی اولیه OpenNext برای Cloudflare Workers در مخزن قرار داده شده است:
- `wrangler.jsonc`
- `open-next.config.ts`
- اسکریپت‌های `preview` و `deploy` در `package.json`

پس از نصب وابستگی‌ها و تأیید دسترسی Cloudflare به مخزن GitHub:
```bash
npm run preview
npm run deploy
``

برای اتصال خودکار مخزن در Cloudflare Workers Builds از build command زیر استفاده کنید:
`npx opennextjs-cloudflare build`
و deploy command:
`npx opennextjs-cloudflare deploy`

## اتصال فروشگاه‌ها
هر منبع باید جداگانه و با API رسمی، فید محصول، قرارداد همکاری یا روش دسترسی صریحاً مجاز متصل شود. دور زدن ورود، CAPTCHA، paywall یا محدودیت‌های فنی مجاز نیست. برای راهبرد فنی به `connectors/README.md` مراجعه کنید.

استخدام، ملک، خدمات و آگهی‌های دست‌دوم باید در جست‌وجوها و مدل‌های داده جداگانه باقی بمانند و با کالاهای فروشگاهی ادغام نشوند.

## رایگان بودن
نسخه اولیه با ابزارهای رایگان قابل آزمایش است، اما سهمیه‌های رایگان محدودیت دارند و ممکن است تغییر کنند. دامنه اختصاصی، پیامک OTP، APIهای تجاری یا مصرف بالاتر ممکن است هزینه داشته باشند. هیچ خرید یا سرویس پولی در این پروژه فعال نشده است.
